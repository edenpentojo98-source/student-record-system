# Student Records System

Class demonstration. Fictional records only.

Live site: https://student-record-system-three.vercel.app

## Features
- Operator sign in with Supabase Auth
- Add / Edit / Delete students
- Search students by name or student number
- Course report using `count_students_by_course` function

## Tech
- Vite + TypeScript
- Supabase (Postgres, Auth, RLS)

## Run locally
```bash
npm install
npm run dev
